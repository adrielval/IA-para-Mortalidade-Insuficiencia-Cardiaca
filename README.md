# IA-para-Mortalidade-Insuficiencia-Cardiaca

O código implementa um modelo de aprendizado supervisionado para prever a mortalidade de pacientes com insuficiência cardíaca, utilizando um classificador de árvore de decisão. A árvore de decisão permite interpretar facilmente quais variáveis (como fração de ejeção, idade, plaquetas e tempo) influenciam mais o resultado.

Esse programa foi feito para uma prova de minha graduação em Ciência da Computação.
